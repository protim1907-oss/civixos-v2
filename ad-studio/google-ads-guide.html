Civix250 Google Ads — Setup Guide

What these ads are: each ad is a finished image (headline, description & button already on it) in two sizes — 1200×628 (rectangle) and 1200×1200 (square) — that links to a matching landing page. Run them as Responsive Display Ads in a Google Display campaign.

⚠ Before you start: These are political / issue ads. Google requires advertiser identity verification (can take a few days), and the Women's Rights ad may need extra certification and can be limited by region. Also set up billing and, ideally, conversion tracking (a Google tag on civix250.ai firing on sign-up).

Step-by-step

  1. New campaign: Google Ads → Campaigns → ＋ New campaign.
  2. Objective: choose Leads.
  3. Campaign type: select Display → Continue.
  4. Settings: name it; set Locations to only the states where sign-up is allowed (TX, CA, IL, MD, CO, NV, OH, GA, MI, NY — confirm current list); set a daily budget; bidding = Maximize clicks to start.
  5. Ad group: create one ad group per ad (cleaner reporting).
  6. Build the ad (Responsive display ad): paste the Final URL; upload the 1200×628 + 1200×1200 images; add the Civix250 logo and business name; fill short headlines/descriptions; CTA = Sign up.
  7. Repeat steps 5–6 for each ad with its own images + URL.
  8. Review → Publish. Ads go "Under review" (~1 day; longer for political).

Good to know

  • The message is already on the image, so keep the text fields short and non-redundant (headlines ≤30 chars, descriptions ≤90).
  • Want the image shown exactly as-is with no Google-added layout? Use "Upload display ads" instead — but that needs standard banner sizes (300×250, 728×90, 160×600, 300×600, 970×250), which can be generated on request.
  • Performance Max is an easier alternative (auto-runs everywhere with the same two image sizes) but gives less control.
  • The same images + URLs also work on Meta (Facebook/Instagram) Ads — square is ideal; vertical 4:5 / 9:16 versions recommended for mobile.
